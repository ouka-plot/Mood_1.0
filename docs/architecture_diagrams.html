图2：音频播放 PCM 数据流

sequenceDiagram
    autonumber
    participant SD as SD卡
    participant WAV as WAV Decoder
    participant EQ as Biquad EQ
    participant DMA_TX as DMA1_S4 TX
    participant I2S as I2S2
    participant ES as ES8388 DAC
    participant SPK as 耳机

    Note over SD,SPK: 音频播放数据链路 - DMA双缓冲 ping-pong

    WAV->>SD: f_read(buf1, 4096)
    SD-->>WAV: PCM数据填充buf1
    WAV->>EQ: audio_eq_process_buffer(buf1)
    EQ-->>WAV: EQ处理完成
    WAV->>SD: f_read(buf2, 4096)
    SD-->>WAV: PCM数据填充buf2
    WAV->>EQ: audio_eq_process_buffer(buf2)

    WAV->>DMA_TX: i2s_tx_dma_init(buf1, buf2, 2048)
    WAV->>I2S: i2s_play_start()

    loop 每次DMA传输完成
        DMA_TX->>DMA_TX: ISR: wav_i2s_dma_tx_callback()
        DMA_TX->>WAV: wavtransferend = 1, wavwitchbuf
        Note over DMA_TX: 自动切换M0AR/M1AR
        WAV->>SD: f_read(空闲buf, 4096)
        SD-->>WAV: 新PCM数据
        WAV->>EQ: audio_eq_process_buffer()
        DMA_TX->>I2S: 发送当前buf
        I2S->>ES: I2S Philips标准
        ES->>SPK: 模拟音频输出
    end

图3：声音监测 + TinyML 推理链路

sequenceDiagram
    autonumber
    participant MIC as ES8388 ADC
    participant I2S_RX as I2S2ext RX
    participant DMA_RX as DMA1_S3 RX
    participant MON as vAudioMonitor
    participant RING as RingBuf 8000样本
    participant ML as vTinyML_Task
    participant UI as vLvgl_Task
    participant LCD as LCD Display

    Note over MIC,LCD: 声音检测 + TinyML 推理链路

    MIC->>I2S_RX: 16kHz/16bit 立体声
    I2S_RX->>DMA_RX: 双缓冲 rx_buf0/rx_buf1

    loop 每512样本 - 32ms
        DMA_RX->>MON: ISR → vTaskNotifyGiveFromISR()
        MON->>MON: extract_mono() 提取单声道
        MON->>MON: calculate_energy() 能量
        MON->>MON: calculate_zcr() 过零率
        MON->>RING: audio_ringbuf_write(mono, 512)

        alt 累积 >= 16000样本 即1秒
            MON->>ML: vTaskNotifyGiveFromISR()
        end
    end

    ML->>RING: audio_ringbuf_read(8000样本)
    ML->>ML: audio_denoise() 谱减法降噪
    ML->>ML: audio_features_extract() 13-MFCC x 31帧
    ML->>ML: audio_classify_run() CNN推理
    ML->>UI: audio_ui_set_classify_result(label, conf)
    UI->>LCD: 显示 baby_cry 95%

图4：BLE + UART EQ 远程控制链路

sequenceDiagram
    autonumber
    participant PHONE as 手机App
    participant BLE as nRF52832 BLE
    participant UART as UART2 串口
    participant EQ_CTRL as vEqCtrl_Task
    participant EQ as audio_eq
    participant WAV as WAV播放
    participant BRIDGE as audio_ui_bridge
    participant UI as LVGL UI

    Note over PHONE,UI: BLE远程EQ控制链路

    PHONE->>BLE: BLE NUS写入 EQ PRESET 2
    BLE->>BLE: nus_received()
    BLE->>UART: uart_poll_out() 逐字节转发

    UART->>EQ_CTRL: eq_ctrl_uart_poll() 行缓冲解析
    EQ_CTRL->>EQ: audio_eq_load_preset(PRESET_ROCK)
    EQ->>EQ: 重新计算5段biquad系数
    EQ_CTRL->>BRIDGE: audio_ui_notify_eq_changed()

    Note over WAV,EQ: 下次DMA回调时EQ立即生效
    WAV->>EQ: audio_eq_process_buffer(pcm)
    EQ-->>WAV: 均衡处理后PCM

    BRIDGE->>UI: 更新EQ页面显示

    EQ_CTRL->>UART: 回复 OK
    UART->>BLE: UART ISR → ring_buf
    BLE->>BLE: main loop drain → ble_send_chunk()
    BLE->>PHONE: BLE NUS通知 OK
